# antikytherameccanism.com

Riproduzione digitale calcolante del meccanismo di Anticitera — quadranti, modello 3D, cielo locale — in italiano, inglese e spagnolo.

- `/` italiano · `/en/` inglese · `/es/` spagnolo
- `/3d/`, `/3d/en/`, `/3d/es/` solo modello 3D

Sito statico servito da GitHub Pages; dominio configurato con il file `CNAME`.
Fonti dei dati: Freeth et al. 2006, 2008, 2014, 2021; Meeus, *Astronomical Algorithms*; JPL Keplerian elements. Dettagli e avvertenze DA VERIFICARE nella Vista esperta di ogni pagina.
